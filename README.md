# Postcards from my Jungle

For this project, I trained a diffusion model to generate fictional animals by experimenting with different epoch levels. Throughout the process, I encountered several challenges, particularly with my Google Colab setup. I often ran out of credits, which caused delays, as I could not continue working until the credits were replenished. Additionally, the inactivity tracker posed another issue; training for 100 epochs required me to monitor the process closely to ensure it continued running, which made the process time-consuming. The limited GPU availability also affected training efficiency, occasionally forcing me to restart sessions. Given these challenges with Colab, I would opt to run the project on my local machine if I were to repeat the project, as this would provide more control and avoid interruptions caused by credit limitations. Running locally would allow for more seamless experimentation without session expirations, improving workflow efficiency.

For generating sounds, images, and text, I based my prompts on actual animal characteristics. This strategy greatly aided the training process for both the images and the text, ensuring the results were realistic and fitting the intended theme. However, the sound generation process was particularly complex, as mapping abstract characteristics to unique, fictional animal noises required iterative refinement. To further improve the quality of my outputs, I would again run the model on my local computer. This would give me more flexibility to experiment with the number of epochs and the random seed, which are key to fine-tuning the quality of the generated images. Additionally, I would explore using larger datasets and alternative diffusion architectures to enhance the diversity of the generated outputs, making the fictional animals more distinct and believable.
